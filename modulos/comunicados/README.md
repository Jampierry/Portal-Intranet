# Módulo comunicados

**Escopo:** central de comunicados com busca e filtros por categoria.

**Status:** Lista e detalhe prontos (`GET /api/comunicados/:slug`, só publicados; tela em `#comunicados/<slug>`). Gestão (criar, publicar, arquivar) pendente: depende do módulo acessos.

**Arquivos:** telas em `web/src/comunicados/`, API em `api/`, dados fictícios (seed) em `data/`, testes em `tests/`.

Regras: ver `../../CLAUDE.md`. Trabalhar um módulo por vez.
